# منابع رایگان و واقعیت هزینه

## OCI Always Free

برای نسخهٔ اولیه، OCI Always Free A1 به عنوان گزینهٔ مرجع در نظر گرفته شده است. مصرف باید داخل سهمیهٔ رسمی Always Free باقی بماند.

در دسترس بودن ظرفیت، region، سیاست ثبت‌نام و شرایط حساب دائمی یا تضمینی نیستند.

## Cloudflare Workers Free

برای control-plane، metadata، health check یا ابزار سبک مناسب است؛ جایگزین یک VM عمومی برای dataplane نیست.

## اصل هزینه

در repo نباید subscription، API پولی، credential پرداختی یا domain purchase لازم باشد.

## محدودیت مهم برای ایران

مسیر واقعی به یک نقطهٔ خروج خارجی نیاز دارد. بنابراین «کاملاً رایگان» در این پروژه به معنی «بدون هزینهٔ سرویس نرم‌افزاری/زیرساختی خارج از سهمیهٔ رایگان» است؛ دسترسی عملی به free-tier provider می‌تواند به کشور، region، ظرفیت و احراز هویت وابسته باشد.


## جزئیات هزینهٔ سمت کلاینت

Jamshidix.exe، sing-box (GPL-3.0)، Go و GitHub Actions برای ریپوی عمومی رایگان‌اند. امضای کد (Authenticode) رایگان نیست مگر از طریق برنامه‌های OSS مثل SignPath Foundation (نیازمند درخواست و تأیید)؛ تا آن زمان hash رسمی Release را ملاک اعتماد قرار دهید.
